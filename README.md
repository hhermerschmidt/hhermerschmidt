## Henning Hermerschmidt

**Dr.-Ing. | Senior Software Engineer**  
*C++ Systems Architecture · HPC · Numerical Methods*

Senior software engineer specialising in high-performance scientific simulation software,
with a focus on software architecture and the long-term evolution of large-scale C++
codebases in performance-critical environments.

Currently at **MAGMA GmbH** (Aachen), where I work on the solver core of a commercial
multi-physics casting simulation platform — bridging numerical methods, domain knowledge,
and robust software design.

### What I work on

- **Software architecture** for large-scale scientific and HPC codebases (C++17/20)
- **Solver development**: FVM, FEM, CFD, free-surface flow, FSI, multi-physics coupling
- **API design and modularisation** — making solver components composable and reusable
  across physical regimes and solver generations
- **Legacy modernisation**: decomposing tightly coupled C/C++ systems into modular,
  testable, maintainable designs
